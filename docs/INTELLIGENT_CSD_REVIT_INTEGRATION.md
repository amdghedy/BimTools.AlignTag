# Intelligent CSD Optimizer - Revit integration status

## What is now integrated

The ALIGN ribbon now includes **CSD Optimize**. The command is read-only and targets Revit 2020 / .NET Framework 4.7.2.

1. Reads native MEP elements in the active view or selection and traverses loaded Revit links visible in the active view. A selected RevitLinkInstance can also be analysed.
2. Supports duct and flex duct, duct fittings/accessories, pipe and flex pipe, pipe fittings/accessories, cable trays/fittings, conduits/fittings, and mechanical/electrical equipment.
3. Reads rectangular, oval and round connector envelopes where available. Round connector diameter is converted to a square section envelope.
4. Uses built-in width/height/diameter parameters as a fallback when connector dimensions are unavailable.
5. Creates candidate arrangements using the existing knowledge-based packing engine.
6. Presents ranked options, clash/clearance/rule metrics, per-element proposed positions, and a separate solver-layout preview.
7. Extracts Revit element solids (including nested family-instance geometry) and transforms linked solids into host coordinates.
8. Creates a 2 mm thick section slab aligned to the active view plane and intersects it with each extracted solid using Revit Boolean operations.
9. Reads the resulting planar section face edge loops, including internal loops, and converts the measured section contours to millimetres in view coordinates.
10. Retrieves separately hosted duct/pipe insulation and duct lining through Revit 2020 InsulationLiningBase APIs and sections their solids independently.
11. Uses transformed linked-element bounding-box intersection against the active crop box rather than filtering links by element centre only.
12. Repositions measured section contours to candidate placement centres and checks candidate pairs for true-profile 2D overlap, with internal void loops excluded from the filled material region.
13. Reports successful solid sections, geometry failures and insulation/lining objects; the candidate table displays measured-profile overlap checks.
14. Records engineer grades in the current session, reports NDCG@5, and exports the selected candidate to CSV.

## Safety boundary

This increment does **not** move, rotate, resize, disconnect, reconnect, or recreate any Revit MEP element. The window is an analysis/review surface only. Exported positions are solver coordinates in millimetres, not a command to modify model geometry.

The extraction adapter traverses loaded RevitLinkInstance documents and applies each link's total transform to the element solids and bounding boxes. Linked-model crop filtering uses transformed bounding-box overlap with the active crop box, which is conservative for non-rectangular crop regions. The actual section view is generated by intersecting Revit solids with a 2 mm thick slab centred on the active view plane. The resulting cap-face edge loops are used as section contours; curved Revit edges are tessellated for display and polygon testing. Insulation and lining are retrieved as separate Revit elements through InsulationLiningBase and sectioned independently. The candidate geometry check translates each measured cross-section to its proposed candidate centre and tests the resulting 2D profiles pairwise, preserving internal void loops. This is a true-profile **2D section check**, not a full 3D routed clash test: it does not validate route continuity, fittings along the entire run, elevation transitions, supports, hangers, access zones, fire-stopping, maintenance clearances or movement feasibility. The 2 mm slab is a finite-thickness Boolean slice, not a zero-thickness analytic intersection. Geometry failures are counted and displayed; a failed solid operation is not replaced with a bounding-box result. Unloadable links are skipped. The solver preview remains a proposal only; the Revit model is never modified.

## Engineering limitations to resolve before construction use

- Improve linked-model extraction with robust visibility/crop-shape filtering, unloaded-link diagnostics, source document version tracking and linked-model performance tests.
- Refine the finite-thickness Boolean section into a configurable precision section workflow; validate section profiles against representative ducts, pipes, cable trays, fittings, equipment and linked-model geometry in Revit 2020.
- Add system-specific rules, project profiles, code/standard checks, insulation and fitting envelopes.
- Add multi-section corridor continuity and utility crossover handling.
- Extend 2D measured-profile validation to 3D route continuity and full-route clash analysis; add an engineer-approved application workflow with transaction rollback.
- Persist profiles, assessments and candidate history; current engineer grades are session-only.
- Add automated unit/integration tests and validate with representative Revit 2020 project models.

## How to run

Open a Revit 2020 project, activate the intended section/coordination view, optionally select the native MEP elements to analyse, then choose **BIM TOOLS > ALIGN > CSD Optimize**. Review the alternatives and export a candidate report if required.

This is an engineering-assistance prototype, not an automatically approved coordinated shop drawing. A qualified MEP engineer must validate all clearances, levels, access, maintainability and project requirements.
